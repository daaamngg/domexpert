# Фото, которые остались маленькими (540 px)

Крупные оригиналы нашлись в группе ВК для первого экрана, обложек блоков и «Наших работ» —
их уже подставил. Ниже — фото, которых в ВК в хорошем качестве нет. Сейчас они стоят только
миниатюрами 64–80 px в списках услуг, там размер не мешает. Улучшать — если захотим показать
их крупно (обложка, «Наши работы»).

Нужное разрешение для крупного показа: **1440×1920** (3:4, как исходник). Минимум — 1080×1440.

После улучшения: положить файл в `photos-src/` под тем же именем → `npm run images`.

## Общее правило для всех промптов
Gemini должен только улучшить качество, а не перерисовать: те же люди, поза, одежда,
инструмент, фон, погода. Если в ответе что-то «додумано» (лишние предметы, другие лица,
новые надписи) — такое фото не берём: это уже не работа Сергея.
